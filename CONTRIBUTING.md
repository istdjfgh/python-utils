# Участь у лабораторній №02

## Для xx1x1x2x

1. Увійти у свій GitHub та прийняти запрошення:
   https://github.com/istdjfgh/python-utils/invitations
2. Клонувати репозиторій:

   ```powershell
   git clone https://github.com/istdjfgh/python-utils.git
   cd python-utils
   python -m unittest discover -v
   ```

3. Погодити задачу у GitHub Issues і створити власну гілку.
4. Внести реальне покращення або тести; використовувати власне ім'я та email у Git.
5. Створити коміт, відправити гілку та відкрити Pull Request у `main`.
6. В описі вказати `Closes #N`, де N — номер відповідного Issue.
7. Попросити іншого учасника переглянути зміни. Review виконує сам рецензент.

Не слід закривати Issue лише тому, що воно створене, або вказувати
схвалення коду, якого насправді не було.

## Навчальний конфлікт

Двоє учасників створюють гілки від однієї версії `main` і змінюють один
рядок README. Після злиття першого PR другий учасник підтягує `main`,
вирішує конфлікт у VS Code, запускає тести й відправляє виправлення.
Скріншоти потрібно зробити під час реального виконання.

## Перевірка перед здачею

- Доповнити команду до 3–4 осіб або погодити інший склад із викладачем.
- Додати справжні ПІБ та групу до звіту.
- Виконати командні PR, review та навчальний конфлікт.
- Зберегти докази роботи з Git у VS Code.
- Кожному учаснику написати власні висновки.
- Подати посилання на репозиторій у завдання №02, коли воно стане доступним.
- Не замінювати вже подану лабораторну №01 матеріалами №02.
