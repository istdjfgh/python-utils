# Участь у проєкті

1. Прийняти запрошення в репозиторій і клонувати його:

   ```bash
   git clone git@github.com:istdjfgh/python-utils.git
   cd python-utils
   python -m unittest discover -v
   ```

2. Взяти завдання в [Issues](https://github.com/istdjfgh/python-utils/issues).
3. Створити гілку від актуальної `main`: `git switch -c feature/<назва>`.
4. Зробити коміти за Conventional Commits від власного імені та email.
5. Відправити гілку й відкрити Pull Request у `main`, в описі — `Closes #N`.
6. Призначити рецензента з команди; злиття — лише після схвалення.
7. Після злиття: `git switch main`, `git pull`, видалити гілку.
